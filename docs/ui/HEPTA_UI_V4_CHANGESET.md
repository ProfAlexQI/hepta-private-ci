# Hepta UI v4 initial changeset

## Source changes

- Added the source-bound UI development plan.
- Added a machine-readable material contract.
- Added capability/authority and visual qualification matrices.
- Added a Web v4 cascade that keeps stable content unblurred, constrains glass
  to chrome/transient roles, raises type and hit-target floors, and presents
  mobile transients as safe-area bottom sheets.
- Added a Native v4 module loaded after the legacy style graph to raise shared
  typography/interaction definitions and publish fail-closed authority flags.
- Added a static gate and dedicated CI workflow.

## Claims deliberately not made

- No browser screenshot has been qualified by this changeset.
- No Native target has been compiled or captured by this document.
- No iOS, Android, Windows or macOS system-material adapter is claimed complete.
- No live adapter, mutation, provider effect, operator acceptance, promotion or
  release authority is enabled.

Runtime and device rows remain `REQUIRED_NOT_RUN` until source-bound evidence is
attached to a frozen candidate receipt.
