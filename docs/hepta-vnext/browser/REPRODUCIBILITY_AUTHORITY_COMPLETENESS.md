# Reproducibility authority completeness

The worker reproducibility comparator is qualification-only. Its runtime/effect/network/product/operator/promotion/release posture must be interpreted together with the repository-wide browser authority contract, which also fixes `g5_allowed=false` and `execute_allowed=false`. A future schema revision will carry those two fields directly; the current comparator cannot grant them because no reproducibility result is an execution admission or authority source.
