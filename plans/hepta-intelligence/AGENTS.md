# Hepta Intelligence session bootstrap

For every audit, design, implementation, review, qualification, or research session in this subtree:

1. Read `HEPTA_INTELLIGENCE_CURRENT_PLAN.json`.
2. Read `HEPTA_INTELLIGENCE_MASTER_PLAN.md`.
3. Treat the master plan as the only current human-readable development plan.
4. Treat all versioned plans, tranche documents, PR bodies, receipts, snapshots, and chat summaries as historical evidence only.
5. Fail closed when branch/head, digest, stage, claim, authority, or document pointers disagree.
6. Execute only the first unblocked action in the canonical plan.
7. While Q0 is active, do not add new runtime source, migrations, H5/H6/H7 runtime tranches, production callers, or CALLERS changes.
8. Do not claim self-evolution, lifelong learning efficacy, experience-shaped intuition, biomimetic neurons, structural plasticity, or neuromorphic behavior without the exact claim-level evidence defined by the master plan.
9. Update the stable master plan instead of creating another dated or versioned master roadmap.
