# Hepta development

`main` is the single development integration line. Module work must name an exact `main` commit and tree as its integration baseline rather than selecting an older implementation, archive or diagnostic branch by name. Retained historical refs are provenance, not competing development authorities. Ref retention and cleanup do not establish qualification, acceptance, runtime activation or release.

The sole global development authority remains [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md). Its recorded administrative default at the V8 cleanup baseline is historical provenance; changing the repository's live default branch is a separate repository-administration action and must be verified from GitHub.

Module teams start at [`docs/modules/README.md`](docs/modules/README.md), which links the forty stable technical development guides and their closed-world source-binding index. These module specifications remain subordinate to the one global plan and must not be deleted merely to reduce the number of Markdown files.

Adaptive and longitudinal specifications start at [`docs/learning/README.md`](docs/learning/README.md). The independent source-byte binding for cited papers is `docs/learning/PAPER_EVIDENCE_BINDINGS.json` and is recomputed from the pinned evidence commit rather than from verifier constants. Do not delete an evidence ref until its pinned objects and verification path are preserved and qualified under the replacement retention scheme.

The distributed CNS, organ graph and embodied-control extension starts at [`docs/cns/README.md`](docs/cns/README.md). HNMF multimodal memory starts at [`docs/hnmf/README.md`](docs/hnmf/README.md). Both are qualification/reference layers and grant no production, physical-effect, acceptance, promotion or release authority.

Implementation-ready state machines, typed readiness protocols, all-module lane bindings, embodied-control coding semantics and explicitly authorized external-system assimilation start at [`docs/readiness/README.md`](docs/readiness/README.md). This layer closes pre-coding documentation ambiguity only.
