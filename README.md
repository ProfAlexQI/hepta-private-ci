# Hepta development

The sole global development authority remains [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).

Module teams start at [`docs/modules/README.md`](docs/modules/README.md), which links the forty stable technical development guides and their closed-world source-binding index.

Adaptive and longitudinal specifications start at [`docs/learning/README.md`](docs/learning/README.md). The independent source-byte binding for cited papers is `docs/learning/PAPER_EVIDENCE_BINDINGS.json` and is recomputed from the pinned evidence commit rather than from verifier constants.

The distributed CNS, organ graph and embodied-control extension starts at [`docs/cns/README.md`](docs/cns/README.md). HNMF multimodal memory starts at [`docs/hnmf/README.md`](docs/hnmf/README.md). Both are qualification/reference layers and grant no production, physical-effect, acceptance, promotion or release authority.

Implementation-ready state machines, typed readiness protocols, all-module lane bindings, embodied-control coding semantics and explicitly authorized external-system assimilation start at [`docs/readiness/README.md`](docs/readiness/README.md). This layer closes pre-coding documentation ambiguity only.
